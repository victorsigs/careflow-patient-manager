# CareFlow Patient Manager

build me a patient manager app. The app is basically a todo list for patient admited and includes current patients and todo list next to them. you can ad patients and ad things to do from presets (ex doppler, CT, MRI) , see drg procedures for references,  add discharge date, investigations to do, also color coded, consoults (color coded with icon by specialty). The app is used for romanian healthcare
